# zagros (زاگرس)

[![DOI](https://zenodo.org/badge/1450016849.svg)](https://doi.org/10.5281/zenodo.24078689)

A Persian-first console for learning Python. A real command prompt (type `run program.py`,
or just the file name) whose output is rendered by the browser's text engine, so mixed Persian/English
lines, digits and punctuation come out in the right order; Python errors are explained in Persian; files
can be dropped on the window; and a "big result" mode shows only the program's output, very large,
like a finished application. Windows-first, zero dependencies.

---

## فارسی

`zagros` یک کنسول واقعی برای آموزش پایتون است که فارسی و انگلیسی را **درست و کنار هم** نشان می‌دهد.
خروجی در یک پنجره‌ی مستقل (Edge یا Chrome در حالت app) نمایش داده می‌شود؛ پس ترتیب کلمه‌ها، اتصال
حروف، ارقام و علامت‌ها را خودِ موتور متن مرورگر درست می‌چیند و کپی‌کردن هم همان چیزی را برمی‌دارد که
می‌بینید.

### نصب و اجرا

```
pip install zagros

zagros                   # پنجره‌ی کنسول با پرامپت؛ دستور تایپ کنید
zagros برنامه.py         # یک فایل را اجرا می‌کند و بعد پرامپت می‌دهد
zagros --result برنامه.py   # «نمایش بزرگ»: فقط نتیجه‌ی برنامه، با خط بسیار درشت
zagros-gui               # همان، بدون پنجره‌ی سیاه (برای میان‌بر ویندوز)
zagros --register        # ویندوز: دو گزینه در منوی راست‌کلیک فایل‌های py
zagros --unregister      # برگرداندن همان
```

### حالت «نمایش بزرگ» (نتیجه‌ی برنامه، بدون حاشیه)

تازه‌کارها نتیجه‌ی برنامه را می‌خواهند، نه توضیح‌های بالا و پایینش. با دکمه‌ی **نمایش بزرگ** در نوار ابزار
(یا `zagros --result`، یا گزینه‌ی «نمایش نتیجه با zagros» در راست‌کلیک) فقط خروجی و خطای برنامه با خط
بسیار درشت دیده می‌شود: بدون بنر، پرامپت، خط «پایان اجرا» و نوار پایین. هر اجرا صفحه را تازه می‌کند،
مثل اجرای یک برنامه‌ی واقعی. `input()` برنامه همان‌جا در خط خودش پرسیده می‌شود. اندازه‌ی خط با
**A+ / A−** یا **Ctrl+چرخ ماوس** تغییر می‌کند و ذخیره می‌شود. با `mode result` و `mode normal` هم می‌توان
تایپ کرد.

### اجرای فایل

```
~/پروژه> run برنامه.py          ~/پروژه> اجرا برنامه          ~/پروژه> برنامه.py
```

فایل را با **ماوس روی پنجره رها کنید** تا اجرا شود (با پوشه‌ی خودش). فایل‌های غیر پایتون (مثلاً csv) با
رها کردن، مسیرشان در خط فرمان درج می‌شود (با Shift برای برنامه‌ها هم همین). مرورگر مسیر فایل را نمی‌دهد؛
zagros فایل را با نام، اندازه و زمان تغییر در پوشه‌ی فعلی، Desktop، Downloads و Documents پیدا می‌کند و اگر
نیافت، یک نسخه‌ی کپی را اجرا می‌کند.

**اجرا با ذخیره:** دکمه‌ی ⚡ (یا `watch برنامه.py`): هر بار فایل را در ویرایشگر ذخیره کنید، برنامه خودکار
دوباره اجرا می‌شود. `new برنامه` فایل تازه می‌سازد، در ویرایشگر باز می‌کند و همین را روشن می‌کند.
`examples` برنامه‌های نمونه (سلام، ماشین‌حساب، حدس عدد، جدول ضرب، …) را می‌سازد و اجرا می‌کند.

| دستور | کار |
|---|---|
| `run فایل` ، `اجرا` | اجرای برنامه |
| `new فایل` ، `جدید` | ساخت برنامه‌ی تازه + ویرایشگر + اجرای خودکار |
| `examples` / `example نام` ، `نمونه` | برنامه‌های نمونه |
| `watch [فایل\|off]` ، `مراقبت` | اجرای خودکار با ذخیره |
| `mode result\|normal` ، `حالت` | نمایش بزرگ / عادی |
| `python` ، `py` | کنسول تعاملی پایتون |
| `pip ...` | نصب کتابخانه (با همان پایتونی که برنامه را اجرا می‌کند) |
| `cd` ، `ls` ، `pwd` ، `edit` | پوشه‌ها و فایل‌ها (`برو`، `فهرست`، `مسیر`، `ویرایش`) |
| `window top\|size\|snap\|lock\|opacity` ، `پنجره` | کنترل پنجره (ویندوز) |
| `clear` ، `history` ، `help` ، `exit` | `پاک` ، `تاریخچه` ، `راهنما` ، `خروج` |
| هر چیز دیگر | مثل ترمینال: `git status` ، `node x.js` ، ... |

کلیدها: **Tab** تکمیل نام فایل و دستور، **↑ ↓** تاریخچه، **F5** اجرای دوباره، **Ctrl+O** باز کردن فایل،
**Ctrl+C** توقف (با همه‌ی زیرپردازش‌ها)، **Ctrl+L** پاک‌کردن، **Ctrl+/−/۰** اندازه‌ی خط،
**PageUp/PageDown** و **Ctrl+Home/End** برای اسکرول. اگر خروجی پر شود اسکرول می‌کند، و وقتی بالا رفته‌اید
دکمه‌ی ↓ برای رفتن به آخر می‌آید و خروجی تازه شما را از جای خواندن نمی‌پراند.

### پنجره (ویندوز)

از نوار ابزار: **همیشه بالا** 📌، **پنجره ▾** برای اندازه‌ی آماده (کوچک/متوسط/بزرگ) یا دلخواه، چسباندن به
نیمه‌ی چپ/راست یا وسط صفحه (کنار ویرایشگر)، **قفل اندازه** و **شفافیت**. جای و اندازه و تنظیمات پنجره بین
اجراها به یاد سپرده می‌شود (در `~/.zagros_settings.json`).

### دکتر خطا و بقیه

- بعد از هر خطا توضیح فارسی و راه‌حل (نام اشتباه، `int("abc")`، فایل پیدا‌نشده، تورفتگی، علامت فارسی
  داخل کد، `float("۳٫۵")` و …).
- ارقام فارسی ورودی (`۱۲٫۵`) پیش از رسیدن به برنامه به `12.5` تبدیل می‌شوند؛ نمایش ارقام خروجی به فارسی
  اختیاری است.
- کپی و ذخیره‌ی خروجی، رنگ ANSI، `\r` برای نوار پیشرفت، پوسته‌ی تیره/روشن؛ اسکریپت‌های Tkinter پنجره‌ی
  خودشان را باز می‌کنند.

### کتابخانه (بدون وابستگی)

```python
from zagros import parse_float, parse_int, normalize_input, to_persian_digits, normalize_persian

parse_float("۳٫۵")            # 3.5
parse_int("۱٬۲۳۴")            # 1234
normalize_input("۱۲٫۵")       # '12.5'
to_persian_digits("سال 1405") # 'سال ۱۴۰۵'
normalize_persian("كتاب")     # 'کتاب'
```

### محدودیت‌ها (صادقانه)

- این یک **شبیه‌ساز ترمینال کامل نیست**. برنامه‌های تمام‌صفحه (vim، htop، curses)، `getpass` و ویرایشگرهای
  داخل ترمینال (مثل `git commit` بدون `-m`) کار نمی‌کنند؛ ورودی و خروجی از لوله (pipe) رد می‌شود.
- کنترل پنجره (همیشه بالا، اندازه، قفل، شفافیت، چسباندن) فقط روی ویندوز و فقط وقتی پنجره‌ی مستقل
  Edge/Chrome باز شده کار می‌کند؛ با API خود ویندوز انجام می‌شود، چون صفحه‌ی وب چنین اجازه‌ای ندارد.
- رها کردن فایل به‌خاطر امنیت مرورگر مسیر را نمی‌دهد؛ پیدا کردن فایل ابتکاری است (نام + اندازه + زمان) و
  فقط در چند پوشه‌ی رایج و تا عمق ۳ می‌گردد.
- تست‌ها روی لینوکس و پایتون ۳٫۱۲ اجرا شده‌اند. کد مخصوص ویندوز (`taskkill`، `chcp`، `os.startfile`، رجیستری،
  و لایه‌ی `ctypes` کنترل پنجره) با شبیه‌ساز تست شده ولی هنوز روی ویندوز واقعی نه.

### امنیت

سرور فقط روی `127.0.0.1` گوش می‌دهد، هر درخواست توکن تصادفیِ همان اجرا را لازم دارد، هدر Host بررسی
می‌شود (جلوگیری از DNS rebinding)، CORS وجود ندارد و صفحه با CSP سخت‌گیرانه (بدون اسکریپت inline) ارائه
می‌شود. آپلود فقط `.py/.pyw` تا ۱ مگابایت با نام پاک‌سازی‌شده است. گزینه‌های راست‌کلیک فقط زیر
`HKEY_CURRENT_USER` می‌نویسند، برنامه‌ی پیش‌فرض `.py` را عوض نمی‌کنند و با `--unregister` کاملاً برداشته
می‌شوند. با بسته‌شدن پنجره، سرور و برنامه‌ی در حال اجرا خودکار بسته می‌شوند.
